# Edge Agent V11.26

## V11.26.0: duplicates merged: one place for each thing

- **One Add a drone list.** The Drone page's list now also has **DJI Fly live stream (video only)**: the RTMP address
  and QR code for DJI Fly, with each stream's state and Copy address. The Devices tab's Drone tab and the Dashboard's
  **+ Add drone** open that list instead of adding a stream straight away.
- **Settings → AI & devices: the switches that really work.** Before, Settings had Camera AI, Face recognition,
  Licence plate recognition, Drone runtime, Drone AI and Drone tracking switches that were saved but changed nothing (the
  working ones were on the Dashboard). Now Settings shows the same live switches as the Dashboard: **Camera AI** (faces
  and number plates are part of it), **Drone AI**, **Drone tracking assist** and **Other objects list**. The Dashboard's
  "Object AI" button is renamed **Other objects list**, which is what it is (other things seen, in a list).
- **GPS dispatch removed from Settings.** It was an unfinished early feature: its camera position and "dispatch" never
  flew a drone (drones are sent to cameras by Drone responses). Camera positions are set in one place, the Drone page
  (an old GPS dispatch position was already copied there); Coverage sets which way each camera looks.
- **Incidents and events together.** One Settings tile, **Incidents & events**: the Incidents page has **All events one
  by one**, the Events page has **Incidents**, and the Dashboard's **Event history** opens the same event list.
- **Users: portal accounts shown.** On a PC paired with the portal, the Users page lists the portal accounts that have
  signed in on this PC with their role, and a button to manage them in the portal; the PC's own accounts are labelled
  **Local accounts (this PC only)**, for people without a portal account.
- Admin portal (website): **Clients** is the one list of clients; the separate Licences list is gone (the licence form
  still opens from a client: New on-prem client, Edit details, Renew, Add contact & limits). **Revoke licence** is on
  the client page, the Clients list has a **No details yet** filter, and there is one place to add clients.
- **Same words everywhere.** "Licence" (as in the admin portal and the documents) on every page, message and on-prem
  guide of the Windows app: the Licence page, its errors ("Not a licence file.", "Licence expired on …") and limits
  messages. DJI's own "App License" field keeps DJI's spelling, and file names (`license.lic`, the signing key, the
  downloaded `.lic` files) are unchanged. The voice assistant asks for the "number plate".
- **Licence page on online PCs.** A PC paired with the portal now shows its **online licence** (plan, status, trial
  end, features, camera and drone use against the limits) instead of the on-prem file page; installing a licence file
  stays available underneath, labelled for a PC without internet.
- Website and customer portal: **AI Security Command Center** everywhere (the sign-in and onboarding pages and the
  website said "Command Centre"; the on-prem edition keeps its own product name and installer file names). The customer
  portal's "AI controls: manual feature overrides" card now shows **Features: how many of the plan's features are
  included** (the plan's, with the provider's changes), and the out-of-date "Drone flight requires a compatible bridge"
  text now says what the Command Center does.
