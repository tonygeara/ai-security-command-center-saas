# Edge Agent V10.8

Windows customer runtime maintenance release.

## Fixes
- Stops drone RTSP probing while Drone runtime is OFF. This removes repeated `DESCRIBE 404` log noise when no drone is connected.
- Makes camera recovery requests idempotent. When automatic recovery is already running, the API now returns HTTP 200 with `state=already_running` rather than HTTP 409.
- Customer UI treats an already-running recovery check as normal background activity.
- Preserves the tested MAC-based camera identity, IP-change recovery, configuration backup/rollback, and V10.7 customer dashboard.

Release package is distributed from the controlled customer build channel. Camera credentials are never included in release artifacts.
