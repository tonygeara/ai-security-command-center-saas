# Edge Agent V11.24

## V11.24.0: Detectors on the Fleet map, and flying despite the weather (the user is asked first)

- **Detectors switch on the Fleet page** (next to Run patrol): shows or hides the drone detectors on the Fleet map: each
  detector's range circle (green; red while it sees an unknown drone; dashed when it is switched off), its name, sensor
  and range, and the unknown drones the detectors see. The choice is remembered in the browser. Shown only when the
  Detector drones tab is on for this PC (licence and Settings → Tabs).
- **Fly despite the weather, with the user's permission:** when the weather (wind, rain, temperature, visibility, or no
  forecast when Flight Safety requires one) is the only thing stopping a flight, the page now asks "Fly anyway despite
  the weather? You are responsible for the flight." and flies if the user agrees. Works for Take off, Send to, Fly
  patrol, Save and fly, dragging a drone on the map (Fleet, Drone and Detector drones pages) and Fly route on the Drone
  page. The route keeps that choice when it is handed over to a backup drone.
  - Crewed aircraft nearby can never be overridden: the flight stays blocked until it has passed.
  - Every flight despite the weather is written to the audit log and the drone's events (who chose it, what the
    weather was).
  - Automatic flights (Run patrol, alarm responses, sending drones to an unknown drone) still never fly in bad weather.
