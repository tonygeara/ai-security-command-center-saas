# Edge Agent V11.4

## V11.4.0: always guarding, required sign-in, audit log

### Keeps guarding when the browser closes
- Closing the browser no longer stops anything: cameras, AI, alerts and drone responses keep running.
  (V11.3.6 stopped the system with the browser; that is now an option, off by default:
  **Settings → System → Stop the system when the browser closes**.)
- **Settings → System → Shut down system** (admins; click twice) stops the dashboard and the AI
  services until the program is started again.
- The program **starts by itself when you sign in to Windows**, in the background (no browser, no
  window). Setup asks with a checkbox, on by default ("Start guarding automatically…"). Opening the
  desktop icon while it runs just opens the dashboard.

### Sign-in is required
- The first time the dashboard opens it asks for an **admin account** (user name and password) before
  anything else; nothing, including drone controls, works until it exists. Installs that already have
  users are not affected. Add viewers and operators under **Settings → Users**.

### Audit log
- **Settings → Audit log** (admins): every drone action and who asked for it (a person on the
  dashboard, a Telegram command, or the system itself: auto-dispatch, scheduled patrols, low-battery
  return, no-fly and landing safety), plus every change to users, safety, licence and system settings.
  Manual stick flying is one line per session, not per movement. Passwords and keys are never written.
- Each line is chained to the one before (SHA-256), so an edited or deleted line is shown as
  **"The log was changed at line N"**. Filter, and download as CSV.
- Stored in `audit_log.jsonl` in the data folder.
