# Edge Agent V11.14

## V11.14.2: updates started from the PC no longer stop the program

- Fixed: **Check now / Install now** (and automatic updates) closed the program and left it stopped, still on the old
  version. The installer stops the running program first, and it stopped everything the program had started,
  itself included. It now stops only the program, finishes the update and starts the new version.
- PCs on V11.13.1–V11.14.1 can update to this version with Install now (or by themselves, with Updates on): the fix
  is in this version's installer. A PC left stopped by the fault: start the program again from its desktop icon
  (or sign in to Windows again), then update.
- Upgrades no longer stop Docker Desktop when it was started by the program.
- Admin portal: the Approve button shows **Approved ✓** when the chosen version is already approved, and a newly
  published version appears within a minute (was up to 10 minutes).

## V11.14.1: Run patrol off sends the drones home

- Switching **Run patrol** off now sends every drone on one of its patrols **home** (round no-fly zones, then it
  lands), instead of leaving it hovering where it was. Stop route on a single drone still hovers it, as before.

## V11.14.0: Run patrol switch for every drone, themed dialogs, free-trial countdown

- New **RUN PATROL** switch beside the live view on the **Drone Control** page (and on the **Drone Grid** page).
  Switched on, every connected drone and every virtual drone takes off by itself and flies **its own last route**,
  again and again, until the switch is turned off.
  - A drone's last route is the one last **flown or saved on its own Drone Control page** (each drone keeps its own).
    A drone with no route yet stays on the ground.
  - Before starting, the switch lists which drone will fly which route and asks you to confirm.
  - Each drone keeps its route's own height, speed, pauses, battery swap level, relay and lost-link settings, and
    the usual checks (licence, connected, GPS, range, no-fly zones, weather, aircraft, battery) before it takes off.
  - A drone sent home by its battery level takes off again by itself once its battery is back above the minimum.
  - **Stop route**, STOP, the pilot taking control or the drone's own safety taking over leaves that drone alone
    (a Telegram message says so) until the switch is turned off and on again. The others carry on.
  - Switching it off stops every patrol it started; those drones fly home (round no-fly zones) and land.
  - The switch stays on after the program restarts. Operators and admins can use it (Viewers can't).
- Under the live view, a line shows each drone's route and what it is doing (flying, waiting for battery, why it
  can't fly). The Drone Grid marks patrolling drones with a **PATROL** tag.

### Themed dialogs everywhere

- Every question, warning and message (delete, take off, remove, rename, errors…) now opens **in the middle of the
  page in the system's own look**, instead of the browser's grey box at the top. Questions about flying, deleting or
  switching off are shown in red, with Cancel picked by default. Esc cancels, Enter confirms.
- Same in the website's customer and admin portals.

### Free trial: time left and a reminder

- On a free trial, every page of the PC dashboard and of the customer portal shows the **time left** at the top right
  (days, hours, minutes, seconds; amber in the last day). It links to Choose a plan.
- **One day before the trial ends**, a reminder opens in the middle of the page (at most once a day) with
  **Choose a plan** or **Later**.
