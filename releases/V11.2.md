# Edge Agent V11.2

Windows customer runtime feature release.

## New
- **3D Maps** tab: draw an area, fly a mapping grid (or import drone photos), and process the images with
  OpenDroneMap into a 3D model (view, turn, measure in the browser), an aerial map over the satellite map and a
  PDF report. The mapping engine is downloaded by Docker the first time a map is processed (several GB).
  See docs/DRONE-3D-MAPS.md.
- **Flight safety** tab, checked before every automatic flight and before take-off from the PC:
  weather limits (Open-Meteo), crewed aircraft (ADS-B: airplanes.live or a local receiver), airports and
  airspace as no-fly zones (OurAirports, GeoJSON), radio coverage with terrain. See docs/FLIGHT-SAFETY.md.
- Drone page: **Shortest order** for patrol routes, **Check signal** per stop, nearby aircraft on the map,
  flight-safety banner.

## Before deploying
- Check the default airport radii against the national rules (Lebanon: DGCA). If a site is inside an imported
  airport zone, flights there are refused until it is marked authorised (only with permission).
- After this installer is distributed, set `LATEST_APP_VERSION` in `lib/admin.ts` to `11.2.0` so the portal
  shows which devices still need the update.
