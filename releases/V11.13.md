# Edge Agent V11.13

## V11.13.3: 14-day free trial

- New clients on **Trial** get the **Business** plan free for **14 days** (the end date is set when the client is
  created; the admin portal shows it on the client's page).
- When the trial ends, until the company's admin chooses a plan:
  - their PCs switch every feature off (even offline: the PC's offline lease ends with the trial) and refuse
    portal sign-in ("Your company's free trial has ended…");
  - the portal only shows **Choose a plan** (Home, Pro or Business through Stripe, or contact for Enterprise), and
    adding users stops.
  - Paying makes the account active on that plan straight away (Stripe), and everything comes back.
- A trial is given **once per email**: the admin portal refuses to start a trial for an email that already had one
  (remembered even after the account or company is deleted) or that already has an account. Such clients can still
  be created on a paid plan.
- Portal: trial clients see "Free trial · N days left".

## V11.13.2: the signed-in role is a link to your dashboard

- In the signed-in badge (bottom left, "👤 name · role"), the role is now a link:
  - an **admin** on an online PC opens the portal in a new tab: super admins land in the **admin portal**, client
    admins in their customer portal;
  - other roles, and every role on an on-prem PC, go to the dashboard on this PC.
- Website: the role in the portal header and the admin menu is a link too (super admins → admin portal; others →
  their dashboard). The new address `/go` sends anyone signed in to their own dashboard.

## V11.13.1: per-client update channels

- With Settings → Updates on, a PC now installs the version its client's **update channel** says (admin portal →
  client → Updates):
  - **Test**: every new version as soon as it is published.
  - **Normal**: the version approved in the admin portal (Overview → Update channels → Approve).
  - **Pinned**: one chosen version.
- A PC never goes back to an older version by itself: a pin older than the PC just stops its updates.
- Settings → Updates shows the channel.
- A paired PC waits until the portal has told it its channel. On-prem PCs (no portal) follow the newest version.
- Fixed: saving the no-fly zones could fail on Windows while another part of the program was reading them ("Access
  is denied"); it now retries for a moment. (This stopped the V11.13.0 build, so V11.13.0 was never published:
  V11.13.1 includes everything listed under V11.13.0.)

## V11.13.0: automatic updates, Log out and turn off, Docker Desktop installed for you

- New **Updates** switch in Settings (admins), **off** by default, in both editions.
  - **On**: the PC checks for a new version every 6 hours. When one is published it downloads the installer for its
    edition (online or on-prem), checks it against the SHA-256 GitHub publishes for it, and installs it silently.
    The program closes and starts again by itself in about a minute. It waits while a drone is answering an alarm
    or any drone or dock is flying, and tries again every 10 minutes.
  - **Off**: nothing is installed, and the PC doesn't check by itself. **Check now** still looks and shows whether a
    new version exists.
  - **Switching it on** while a new version is waiting asks first: **Install now** or **Not now**. "Not now" skips
    that version; later versions install by themselves.
  - **Install now** is also offered whenever a new version is available.
- Every change and every installation is in the audit log.
- Install guides updated (Updates section).

- **Log out and turn off** (Settings → System, admins): signs out and stops everything on the PC, **Docker Desktop
  included**. The program, and Docker with it, starts again at the next Windows sign-in (the program makes sure it is
  set to start with Windows) or from the desktop icon.
- **Docker Desktop missing**: when the program starts on a PC without Docker Desktop, the start page (or the control
  window) asks **Install Docker Desktop / Not now**. On yes it uses an installer next to the program or on the
  on-prem USB folder, or downloads it from Docker; runs it only if it carries Docker Inc.'s valid code signature;
  installs it with Windows' permission prompt (WSL 2); then starts Docker and sets up the AI services (containers)
  by itself. If Docker needs a restart to finish, it says so, and the program continues after the restart.
