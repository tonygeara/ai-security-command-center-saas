# V10.9 Network Roaming

Windows Edge Agent maintenance release.

- Detects the Windows PC moving between Wi-Fi/router networks.
- Keeps the learned physical camera MAC as the primary camera identity.
- Rediscovers the same camera after DHCP/IP changes on the active reachable LAN.
- Refuses to send camera credentials to a stale/reused IP when the learned MAC does not match.
- Preserves the existing Frigate backup/rollback workflow and changes only the camera host/path.
- Recovery interval reduced to 10 seconds for faster network transitions.
- Customer UI reports Network changed, Finding camera, and Reconnecting states.
- Retains V10.8 disconnected-drone and idempotent recovery fixes.

The PC must still have IP reachability to the camera. A camera isolated on a different Wi-Fi/LAN cannot be reached until it joins a reachable network.
