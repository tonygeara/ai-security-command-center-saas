# Edge Agent V11.19

## V11.19.0: PX4 / ArduPilot drones (MAVLink) and an Add a drone list; Remote ID receivers on Detector drones; backup drone switch; drone distance limit off for now

- **Add a drone: choose the kind of drone from a list** (Drone page → **+ Add drone**, page `/drone-add`):
  - **Ready now**: DJI (Drone Link app), **PX4**, **ArduPilot**, other **MAVLink / MAVSDK** autopilots (also SITL
    and Gazebo simulators), DJI Dock, Virtual drone.
  - **On request** (they need a partner agreement): Azur Drones (Skeyetech), Asylon (DroneSentry), Nightingale
    Security, Percepto, Sunflower Labs, Autel Robotics (EVO II / Max, EVO Nest), FlytBase, ROS 2. "Send request"
    emails the provider (it appears under Admin → Demo requests); on-prem PCs only note it.
  - **Others (find it automatically)**, last in the list: the PC listens for about 6 seconds on the usual MAVLink
    ports (14550, 14540, 14551, 14560), says what it found (for example "ArduPilot quadcopter" or "PX4 fixed wing")
    and adds the one you choose.
- **PX4 and ArduPilot drones** connect over MAVLink through a telemetry radio, a companion computer or the network
  (`udpin:0.0.0.0:14550`, `tcp:<address>:5760`, ...). Each is linked to the PC like a Drone Link phone, so the live
  map, routes, Run patrol, drone responses, the backup drone, no-fly zones and the Drone Grid all work with them:
  take-off, fly to a point, return home, land, camera photo / video and gimbal (when the drone has a MAVLink camera),
  and lost-link action. Keyboard and gamepad flying works on ArduPilot (not yet on PX4). Video: add the drone's video
  stream as a camera. Counted in the licence's drone limit; admins add and remove them.
- **Remote ID** on the Detector drones tab. Most drones over 250 g broadcast their ID, position, height and their
  pilot's position. A Remote ID receiver on the site's network (for example an ESP32 OpenDroneID receiver, a phone
  relay or a commercial sensor) sends what it hears to this PC, and those drones count like any other:
  - a drone that isn't yours raises the alarm when it enters a detector's range, with its **Remote ID** and **where
    its pilot is** (distance from the detector and position); the map shows the pilot and a line to the drone;
  - your own drones broadcast Remote ID too: one heard where one of your linked drones is, is that drone (no alarm),
    and any Remote ID drone can be marked as yours under **My drones**.
- How receivers connect (Detector drones → **Remote ID receivers**):
  - **UDP**: switch on "Listen for receivers on UDP" and set the port (47911 by default); receivers on the site
    network send their JSON there;
  - **HTTP**: POST the JSON to `/api/remoteid/report` on this PC with the header `X-RemoteID-Token` (admins see the
    address and token there, and can make a new token).
  - Simple messages (`{"id", "lat", "lon", "alt", "operator_lat", "operator_lon"}`) and OpenDroneID-style messages
    ("Basic ID", "Location/Vector Message", "System Message") are both understood.
  - To try it without a receiver: `edge/tools/remoteid_send.py` pretends to be one and flies a test drone.
- **Backup drone with each response** (Drone tab → Drone responses → switch, off by default): with every drone
  response (sent by hand, by Auto-send or by camera-to-drone handoff), the next ready drone also flies to the spot,
  25 m to the side and 10 m higher, hovers there with its camera ready to take over, and returns home when the
  response ends (also when the first drone is recalled). Needs a second connected drone with enough battery; if none is
  ready, the response goes ahead and the log says so.
- **No distance-from-home limit for now** (it was 500 m): route stops, fly-to-a-point, drone responses and camera
  positions are no longer refused for being far from the drone's home point, and the Drone page shows no range ring.
  The height limit (120 m), no-fly zones, weather and battery checks still apply. Keep the drone in sight and within
  the controller's range. This limit is to be put back later.
