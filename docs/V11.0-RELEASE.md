# V11.0 Customer Platform

## Cloud
- Login/sign-up continue through Supabase Auth.
- Customer portal now includes a clear Open Command Center action, Edge Agent health, plan, video source count, device/source cards and pairing.
- Super Admin now has a professional operations console with user directory, organizations, subscriptions, Edge Agents, video sources and feature controls.
- Added a protected super-admin-only user directory RPC; ordinary authenticated users cannot enumerate accounts.

## Windows Edge
- Professional customer dashboard retained.
- Settings page centralizes Camera AI, Face AI, LPR, Drone Runtime, Drone AI, Drone Tracking and GPS Dispatch controls.
- Add Device routes to local discovery for cameras/stream candidates.
- V10.9 MAC-based camera identity and Wi-Fi/network roaming recovery retained.
- GPS Dispatch stores camera coordinates locally and exposes readiness/safety status.

## GPS Dispatch safety gate
The current DJI RTMP video path is not a flight-control API. V11.0 does not falsely issue aircraft movement from the web UI. Dispatch remains blocked until a compatible authorized flight-control bridge is installed and can enforce operator confirmation, geofence, GPS/home point, battery and return-to-home checks.
